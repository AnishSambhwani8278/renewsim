# 🌿 RenewSim - Renewable Energy Simulator

**RenewSim** is a dynamic, interactive simulation dashboard that helps users explore how different environmental conditions and renewable energy sources affect energy production, storage, and consumption.

## 🚀 Features
- 🌤️ Select from locations like deserts, coasts, or mountains
- 🌦️ Simulate weather conditions (sunny, cloudy, windy, rainy)
- ⚡ Enable/disable energy sources: Solar, Wind, Hydro, Geothermal
- 🎛️ Adjust demand and storage capacity
- 📊 Visualize power generation, battery storage, and energy consumption in real-time

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript
- Tailwind CSS for UI
- Chart.js for graphs
- GSAP for animations
- Font Awesome for icons

## 🎯 Purpose
Built to educate and raise awareness about renewable energy systems in an engaging and accessible way.
